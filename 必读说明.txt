【*】 程序简介
-工程名称：FreeRTOS 多任务小车控制工程（步进电机 + IMU + OLED + 上位机）
-实验平台: STM32F407VET6最小系统开发板
-MDK版本：5.16
-ST固件库版本：STM32F4xx 标准外设库 1.8.0
-RTOS：FreeRTOS（内核源码在 FreeRTOS/ 目录，heap_4 内存管理）

【 ！】功能简介：
基于 FreeRTOS 的四轮步进电机小车（麦克纳姆轮）控制工程：
- 4 个 Emm_V5 闭环步进电机（张大头协议），支持小车前进/后退/左右平移/斜向平移
- 机械臂电机（上层/下层）位置控制与脉冲读取
- WIT 维特智能 IMU（陀螺仪），通过 USART6 读取 Yaw / x / y 姿态与位置数据
- 增量式 PID 速度控制（increpid）
- OLED 实时显示运行状态、速度、Yaw、x/y 坐标
- 上位机协议解析（host_parse），通过调试串口通信
- 按键任务用于模式切换

【 ！！】注意事项：
- User/ 下存在部分重复/遗留目录（bsp/ 与根级 key、led、exti，User/stm32f10x_conf.h
  为 F1 遗留文件），实际以 main.c 中引用的 bsp_key / bsp_led / bsp_debug_usart 等为准。
- 修改串口配置时注意三个串口分工不同，波特率见下方"串口分配"。

/*********************************************************************************************/

【*】 FreeRTOS 任务分配（见 User/main.c）

	AppTaskCreate	优先级1	创建所有任务后自删除
	OLED_Task		优先级2	100ms 周期刷新 OLED 显示（vTaskDelayUntil）
	KEY_Task		优先级3	按键扫描与模式切换
	Main_Task		优先级4	主逻辑（上位机命令解析、运动模式调度）
	MOTOR_Task		优先级5	电机队列处理与电机控制

	任务间通过消息队列 Motor_Queue（xQueueCreate）传递电机控制命令。

/*********************************************************************************************/

【*】 引脚分配

按键（按下为高电平，硬件去抖）：
	KEY1 <---> PA0
	KEY2 <---> PC13

LED（低电平点亮）：
	LED1 <---> PB5
	LED2 <---> PB0
	LED3 <---> PB1

OLED（软件 I2C）：
	SCL <---> PD1
	SDA <---> PD0

/*********************************************************************************************/

【*】 串口分配

	USART1	PA9(TX) / PA10(RX)	9600	调试串口 + 上位机协议（host_parse），
										USART1_IRQHandler 在 main.c 中
	USART2	-					-		Emm_V5 电机通信（FIFO 缓冲，含 IDLE 中断）
	USART3	-					-		Emm_V5 电机通信（FIFO 缓冲，含 IDLE 中断）
	USART6	PC6(TX) / PC7(RX)	230400	WIT IMU 姿态数据（wit_c_sdk）

/*********************************************************************************************/

【*】 时钟

A.晶振：
-外部高速晶振：8MHz（SetSysClockTo168M 在 User/main.c 中配置）
-RTC晶振：32.768KHz

B.各总线运行时钟：
-系统时钟 = SYSCLK = AHB1 = 168MHz
-APB2 = 84MHz
-APB1 = 42MHz

/*********************************************************************************************/

【*】 目录结构

	FreeRTOS/		FreeRTOS 内核源码（src、include、port/RVDS、MemMang/heap_4）
	Libraries/		CMSIS + STM32F4xx 标准外设库
	User/main.c		入口、任务创建与各任务主体
	User/Emm/		Emm_V5 步进电机驱动、板级支持、FIFO、串口
	User/moter/		Moter.c 小车/机械臂运动控制封装
	User/pid/		增量式 PID（increpid）
	User/host/		上位机协议解析（host_parse）
	User/wit_c_sdk/	WIT IMU SDK + USART6 驱动
	User/OLED/		OLED 驱动（软件 I2C）与字库
	User/bsp/		按键、LED、调试串口、外部中断驱动
	Output/			Keil 编译产物
	Listing/		map / lst 文件
